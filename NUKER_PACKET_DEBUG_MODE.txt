PeoClient 1.21.4 - Nuker Packet Debug Mode

This build is intended for testing the Nuker implementation without anti-cheat
evasion/spoofing.

Debug mode should record:
- movement/rotation packets generated by the Nuker
- block-digging action packets
- target count and Multi value
- break attempts/successes
- tick interval between interactions

The Locked Area / Highlight behavior remains unchanged.

No position spoofing, movement spoofing, packet-order spoofing, or other
anti-cheat bypass mechanism is included.
