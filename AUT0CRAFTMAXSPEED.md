# AutoCraftMaxSpeed

New module for PeoClient 1.21.4.

Settings:
- Craft speed: 1-36 stacks/tick
- Drop speed: 1-36 stacks/tick
- Rare threshold: 1-36 inventory stacks

Craft targets: coal, redstone, lapis, raw gold, gold, raw iron, iron, emerald and diamond blocks.
Drop targets: cobblestone, stone, raw gold block and raw iron block.

The module uses the server-provided crafting/handled GUI and dynamically locates the hopper/action item in the combine GUI.
