# PeoClient 1.21.4

Fabric client mod for Minecraft 1.21.4 containing the requested subset:
- Xray: fluids, opacity/alpha, hide surface, editable Xray block set.
- Nuker: Normal / SurvMulti / Multi / Instant, Multi amount, cooldown, Cube/Sphere, range, sorting, filter, whitelist, raycast, flatten, rotate/no-particles/highlight settings persisted.
- Fullbright: Table / Gamma / Potion and adjustable gamma.
- InventoryCleaner: LiquidBounce-style limits, greedy mode, hotbar target categories, offhand target and item blacklist.

The implementation is a clean 1.21.4 Fabric port rather than the complete BleachHack/LiquidBounce codebase.

Build through GitHub Actions; Java 21 is required by Minecraft 1.21.4.
